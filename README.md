# Калькулятор личных финансов

## Описание
Консольное приложение для учета личных доходов и расходов. Позволяет добавлять операции, категоризировать их, а также отслеживать текущий баланс.

## Установка и запуск
Для работы приложения необходим Python версии 3.7 или выше.
1. Склонируйте репозиторий:
   `git clone https://github.com/ВАШ_НИКНЕЙМ/personal-finance-calculator.git`
2. Перейдите в папку проекта:
   `cd personal-finance-calculator`
3. Запустите приложение:
   `python src/main.py`

## Использование
После запуска приложения вам будет доступно интерактивное меню:
1. **Добавить операцию** — введите тип (доход/расход), сумму, категорию и дату (или оставьте пустым для текущей даты).
2. **Показать все операции** — выводит список всех ранее введенных записей.
3. **Показать баланс** — выводит разницу между доходами и расходами.
4. **Выход** — завершает работу программы.
